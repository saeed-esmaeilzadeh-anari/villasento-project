# ویلاسنتو (VillaSento) — سامانه تخصصی املاک تفریحی و مسکونی

پلتفرم کامل **خرید و فروش، رهن و اجاره باغ، ویلا، باغ‌ویلا و املاک تفریحی و مسکونی** با سه بخش مجزا: سایت عمومی، پنل کاربری (مالک/مشاور) و داشبورد مدیریت. تمام بخش‌ها به دیتابیس واقعی (SQLite از طریق Prisma) متصل هستند و هیچ داده‌ای Mock نیست.

> **بک‌اند:** API کامل Next.js (Route Handlers + سرویس‌لایر) در `src/app/api` و `src/server/services` — اعتبارسنجی Zod سمت سرور، کنترل دسترسی نقش‌محور، Audit Log و Rate Limiting. یک بک‌اند NestJS تجربی مبتنی بر دامنه قبلی (اجاره روزانه) نیز در `mini-services/vilasa-backend/` حفظ شده است (جزئیات در `docs/nestjs-backend.md`).

---

## 🚀 اجرا

```bash
bun install                # یا npm install
npx prisma db push         # ایجاد/به‌روزرسانی جداول
bun scripts/seed.ts        # داده‌های نمایشی (شهرها، مناطق، املاک، مشاوران، مقالات…)
bun run dev                # http://localhost:3000
bun run lint               # ESLint
bunx tsc --noEmit          # بررسی TypeScript
```

## 👤 حساب‌های نمایشی

ورود با **شماره موبایل + رمز عبور** یا **کد OTP** (در حالت نمایشی کد در پاسخ API برگردانده می‌شود). رمز همه حساب‌های دمو: `123456`

| نقش | شماره موبایل |
|---|---|
| مدیر ارشد (SUPER_ADMIN) | `09120000001` |
| مدیر محتوا (ADMIN) | `09120000006` |
| مشاور املاک ۱–۳ (AGENT) | `09120000002` تا `09120000004` |
| مالک ۱ (OWNER) | `09120000005` |
| مالک ۲ (OWNER) | `09120000007` |
| کاربر عادی (CUSTOMER) | `09123456789` |

## 🧩 بخش‌ها

### سایت عمومی
- **صفحه اصلی:** جستجوی پیشرفته (نوع معامله، استان/شهر/منطقه، نوع ملک)، دسته‌بندی‌ها با شمارش واقعی، آگهی‌های ویژه، جدیدترین‌ها، پربازدیدها، خدمات، مشاوران املاک، مقالات، بنرهای مدیریت‌شده، آمار، سؤالات متداول — همه از `/api/home`
- **جستجو:** فیلترهای کامل **سمت سرور** — نوع معامله (فروش/رهن کامل/رهن و اجاره/اجاره)، نوع ملک، استان/شهر/منطقه، بازه قیمت، متراژ زمین و بنا، اتاق خواب، امکانات، وضعیت سند، امکان توافق، فقط ویژه + مرتب‌سازی (جدیدترین/ارزان‌ترین/گران‌ترین/پربازدیدترین) + صفحه‌بندی + **نمایش نقشه و جستجوی محدوده‌ای**
- **صفحه ملک:** گالری تمام‌صفحه، ویدئو/تور مجازی، مشخصات کامل (متراژ، سند، سال ساخت…)، توضیحات، امکانات، **نقشه موقعیت**، کارت مالک/مشاور با تماس و پیام، **درخواست بازدید**، علاقه‌مندی، مقایسه، اشتراک‌گذاری، **گزارش آگهی نامعتبر**، املاک مشابه، شمارش بازدید، JSON-LD (RealEstateListing)
- **مقالات:** فهرست با دسته‌بندی، صفحه مقاله با مقالات مرتبط
- **صفحات ثابت CMS** + فرم تماس واقعی (`POST /api/contact`)

### پنل کاربری (`/#/account`)
نمای کلی با آمار، **آگهی‌های من** (ویرایش/ارسال برای تأیید/تمدید/حذف + نمایش دلیل رد)، فرم ثبت آگهی **۶ مرحله‌ای** با آپلود تصویر واقعی (WebP + progress)، درخواست‌های بازدید (ارسالی و دریافتی + تاریخچه پیگیری)، پیام‌ها، علاقه‌مندی‌ها، مقایسه املاک، تاریخچه بازدیدها، اعلان‌ها، تاریخچه فعالیت و پروفایل/رمز عبور

### داشبورد مدیریت (`/#/admin`)
- **داشبورد:** ۱۲ کارت آمار واقعی + نمودار بازدید/ثبت آگهی/کاربران جدید + توزیع وضعیت + آخرین آگهی‌ها، درخواست‌ها و فعالیت‌ها
- **مدیریت آگهی‌ها:** جستجو/فیلتر، تأیید و انتشار، تأیید بدون انتشار، رد با دلیل، لغو انتشار، بایگانی، انتشار مجدد، ویژه‌سازی، تخصیص مشاور، حذف — با **قوانین انتقال وضعیت** (DRAFT→PENDING→PUBLISHED/APPROVED/REJECTED/EXPIRED/ARCHIVED)
- **کاربران:** نقش‌ها (SUPER_ADMIN/ADMIN/AGENT/OWNER/CUSTOMER)، مسدودسازی، جزئیات و فعالیت هر کاربر
- **مشاوران:** افزودن/ویرایش مشاور با پروانه، فعال/غیرفعال، **گزارش عملکرد** (آگهی‌ها، بازدیدهای موفق، بازدید کل)
- **درخواست‌ها و پیام‌ها:** مدیریت درخواست بازدید (وضعیت، تخصیص مشاور، یادداشت، تاریخچه)، پیام‌های تماس، **گزارش آگهی نامعتبر و پشتیبانی**
- **مدیریت محتوا:** مقالات + دسته‌بندی، بنرها (۴ موقعیت)، سؤالات متداول، صفحات ثابت
- **تنظیمات:** هویت برند، سئو، قوانین آگهی، نقشه، پیامک/ایمیل، آپلود
- **لاگ فعالیت‌ها** + **خروجی CSV** (آگهی‌ها/کاربران/درخواست‌ها — سازگار با Excel)

## 🗄️ دیتابیس

## 🔐 امنیت
- اعتبارسنجی Zod در همه endpoint ها + پیام خطای فارسی یکپارچه
- نشست کوکی امضاشده HMAC (httpOnly، SameSite=Lax)
- کنترل نقش سمت سرور (`requireRole`، `adminGuard`) — نه فقط مخفی‌سازی UI
- Rate Limiting (OTP، ثبت آگهی، درخواست بازدید، گزارش، تماس، آپلود)
- آپلود: فقط JPG/PNG/WebP، حداکثر ۵MB، بررسی MIME واقعی با sharp، خروجی بهینه WebP، ذخیره خارج از مسیر public و سرو از `/api/files` با مسیر ایمن
- Audit Log برای عملیات حساس مدیریتی
- رمز عبور: scrypt با پارامترهای صریح (N=16384) — سازگار بین ران‌تایم‌ها
